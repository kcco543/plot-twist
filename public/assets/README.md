# Placeholder art

Everything in this folder is temporary placeholder art. Replace any file with your own illustration (keep the filename), or add new files and update `src/assets/manifest.ts`.

- `ui/` title screen background
- `worlds/` one illustration per world (8:5)
- `environments/` one room/map per environment type (8:5)
- `characters/` portraits (1:1) and in-game sprites (2:3), in matching numbered pairs
